# 🐘 Create the Postgres Database in Neon

## 📌 Objective

By the end of this guide, you will be able to:

* Create a **PostgreSQL database** in Neon.
* Get your **database connection string**.
* Identify the required **database credentials**:

  * Host
  * Database name
  * Username
  * Password
* Store the connection string securely as an **environment variable**.
---

## Why Neon?

Neon is a fully managed, serverless PostgreSQL database that can be ready in minutes.

:::tip[Why Neon?]

**1. ⚡ Serverless**  
No servers to provision or infrastructure to maintain.

**2. 🌿 Database Branching**  
Create isolated database environments for development and testing.

**3. 💰 Generous Free Tier**  
Start developing without the overhead of a traditional database server.

:::

Follow the steps below to configure Neon for our application.


---

## Step 1 — Create Your Project

1. Head over to **[neon.com](https://neon.com/)**.
2. **Sign up** for a free account (GitHub, Google, or email).
3. Create a new **Organization** — this will hold all your team's projects.
4. Click **New Project** and give it a name (e.g. `my-app-db`).

:::info[Info]
Each Neon project comes with a default database and a ready-to-use connection branch, so you can start querying immediately after creation.
:::

---

## Step 2 — Get Your Connection String

Once your project is created:

1. Go to the **Connect** button on your project dashboard.
2. Copy the connection string — it will look like this:

```txt
<Database client>://<Username>:<Password>@<Host>/<Database name>
```

**Example:**

```txt
postgresql://neondb_owner:****************@ep-autumn-river-ax68f9tr-pooler.c-4.us-east-2.aws.neon.tech/neondb?sslmode=require&channel_binding=require
```

<Admonition type="warning" title="Keep it secret! 🔒">
Your connection string contains your database password. **Never commit it to version control.** Store it in a `.env` file and add that file to `.gitignore`.
</Admonition>

---

## Step 3 — Use It in Your App

Add the connection string to your environment variables:

```bash title=".env"
DATABASE_URL="postgresql://neondb_owner:****************@ep-autumn-river-ax68f9tr-pooler.c-4.us-east-2.aws.neon.tech/neondb?sslmode=require&channel_binding=require"
```

Your application can now read `DATABASE_URL` to connect to Postgres. ✅
